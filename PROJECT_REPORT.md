# 📊 Inventory Management Dashboard - Project Report\n\n**Author:** Chandershekhar  \n**Date:** May 28, 2026  \n**Project Status:** ✅ Complete & Production Ready  \n**Version:** 1.0.0\n\n---\n\n## 🎯 Executive Summary\n\nThis project demonstrates **advanced Excel proficiency** and **business intelligence skills** by developing a fully functional, zero-macro inventory management system. The dashboard serves as both a **production-ready tool** and a **portfolio showcase** for data analysis, visualization, and spreadsheet engineering capabilities.\n\n### Key Achievements\n- ✅ Built a complete 4-sheet data architecture from scratch\n- ✅ Implemented dynamic PivotTable-based calculations\n- ✅ Created an interactive dashboard with real-time KPI updates\n- ✅ Designed professional visualisations (line charts, donut charts, bar charts)\n- ✅ Zero macros/VBA — works on any machine without security warnings\n- ✅ Fully extensible and production-ready\n\n---\n\n## 📋 Project Overview\n\n### Problem Statement\nWarehouses and inventory teams need a way to:\n- Track stock levels across multiple shelves and product lines\n- Monitor reorder levels and identify critical stock situations\n- Visualise trends and patterns in inventory movement\n- Make quick decisions based on real-time data insights\n- Do all of this **without expensive software** or **database systems**\n\n### Solution Delivered\nA **comprehensive Excel dashboard** that combines:\n- Real-time KPI metrics (4 live cards that update on filter changes)\n- Interactive filtering by shelf and product\n- Professional trend analysis (12-month stock trend)\n- Automated alerts for low/critical stock items\n- Fully audit-able transaction log\n\n---\n\n## 🏗️ Technical Architecture\n\n### Workbook Structure (4 Sheets)\n\n```\n📊 Inventory Management Dashboard.xlsx\n│\n├─ 📊 Dashboard [Front-end]\n│  ├─ 4x KPI Cards (live calculations)\n│  ├─ 12-Month Stock Trend Chart\n│  ├─ Bottom-10 Stock Alert Table\n│  ├─ Shelf Slicer (dynamic filter)\n│  └─ Product Name Slicer (drill-down filter)\n│\n├─ 📋 Products [Master Data]\n│  ├─ Product ID (P-001 to P-020)\n│  ├─ Product Name\n│  ├─ Shelf Assignment (1-5)\n│  ├─ Re-Order Level (threshold)\n│  └─ Re-Order Quantity (suggested qty)\n│\n├─ 📝 Transactions [Raw Data]\n│  ├─ Date (transaction timestamp)\n│  ├─ Product ID (foreign key)\n│  ├─ Type (Receipt / Dispatch)\n│  └─ Quantity (+ve = in, -ve = out)\n│\n└─ ⚙️ Calculation [Engine Layer]\n   ├─ Total Received aggregation\n   ├─ Total Dispatched aggregation\n   ├─ Monthly trend data (Jan-Dec)\n   ├─ Per-product availability\n   └─ Bottom-10 sorted ranking\n```\n\n### Key Formulas & Functions Used\n\n| Technique | Purpose | Complexity |\n|-----------|---------|------------|\n| **SUMIF / SUMIFS** | Conditional aggregations for KPI cards | ⭐⭐⭐⭐ |\n| **COUNTIF / COUNTIFS** | Low/Critical stock counting logic | ⭐⭐⭐ |\n| **GETPIVOTDATA** | Dynamic references to PivotTable values | ⭐⭐⭐⭐⭐ |\n| **INDEX / MATCH** | Flexible product lookups | ⭐⭐⭐⭐ |\n| **PivotTable Engine** | Multi-dimensional data aggregation | ⭐⭐⭐⭐⭐ |\n| **Dynamic Named Ranges** | Auto-expanding data ranges | ⭐⭐⭐⭐ |\n| **Data Validation** | Dropdown filters & constraints | ⭐⭐⭐ |\n\n---\n\n## 📊 Dashboard Features\n\n### 1️⃣ KPI Cards Raw Transaction Entry\n   ↓\n   Transactions Sheet\n   (Date | Product ID | Type | Qty)\n   ↓\n2. PivotTable Processing\n   ↓\n   Calculation Sheet\n   (Multi-dimensional aggregation)\n   ↓\n3. Dashboard Visualization\n   ↓\n   Dashboard Sheet\n   (KPI Cards | Charts | Slicers)\n   ↑\n   (GETPIVOTDATA References)\n```\n\n### Formula Examples\n\n**KPI Card - Total Received:**\n```excel\n=GETPIVOTDATA(\"Quantity\", $B$2, \"Type\", \"Receipt\")\n```\n\n**KPI Card - Available (Current):**\n```excel\n=SUMIF(Products!$A:$A, IFERROR(Slicers!$B$2, \"*\"), Calculation!$C:$C)\n```\n\n**Low Stock Alert:**\n```excel\n=IF(C2 < VLOOKUP(A2, Products!$A:$E, 4, 0), \"LOW\", \"OK\")\n```\n\n---\n\n## ✅ Quality Assurance\n\n### Testing Performed\n\n- ✅ **Data
