## 🧠 About the Project

> **A fully interactive, zero-macro inventory management system built entirely in Microsoft Excel** — demonstrating advanced spreadsheet engineering, data modelling, and dashboard design skills.

This project solves a real-world warehouse problem: how to **track, visualise, and act on stock levels** across multiple shelves and 20 product lines — all without a database, without code, and without plugins.

It's designed as both a **production-ready business tool** and a **portfolio piece** that showcases:

- 📐 Structured data modelling across multiple sheets
- 📊 Dynamic PivotTable-powered calculations
- 🎛️ Interactive slicers and filters
- 🚨 Automated reorder-level alerting logic
- 📈 Time-series trend visualisation (12-month stock trend)
- 🔢 Real-time KPI cards that update on every filter change

## 🗂️ Workbook Architecture

```
📁 Inventory_Management_Dashboard.xlsx
│
├── 📊 Dashboard          ← Interactive front-end view
│     ├── KPI Cards (Total Received / Dispatched / Available / %)
│     ├── Stock Availability Trend (12-month line chart)
│     ├── Bottom 10 Stock Quantity (colour-coded table)
│     ├── Shelf Slicer
│     └── Product Selector
│
├── 📋 Products           ← Master product catalogue
│     ├── Product Id (P-001 to P-020)
│     ├── Product Name
│     ├── Shelf Assignment (Shelf 1–5)
│     ├── Re-Order Level
│     └── Re-Order Quantity
│
├── 📝 Transactions       ← Raw event log (source of truth)
│     ├── Date
│     ├── Product Id
│     ├── Transaction Type (Receipt / Dispatch)
│     └── Quantity (positive = in, negative = out)
│
└── ⚙️ Calculation        ← PivotTable engine layer
      ├── Total Received aggregation
      ├── Total Dispatched aggregation
      ├── Monthly trend data (Jan–Dec)
      ├── Per-product availability
      └── Bottom-10 sorted stock ranking
```

## 🚀 Quick Start

### Prerequisites
- Microsoft Excel **2016 or later** (Windows or Mac)
- No additional software, plugins, or macros required

### Installation

```bash
# 1. Clone this repository
git clone https://github.com/Chandershekhar-built/Sales-Inventory-Management-Dashboard-Excel-VLOOKUP-Pivot-Tables.git

# 2. Navigate to the project folder
cd Sales-Inventory-Management-Dashboard-Excel-VLOOKUP-Pivot-Tables

# 3. Open the file in Excel
open Inventory_Management_Dashboard.xlsx
```

Or simply **[⬇️ Download the .xlsx file directly](#-download)** from this repository.

### First Steps

1. Open the file in Excel and click **Enable Editing** if prompted
2. Navigate to the **📊 Dashboard** sheet
3. Use the **Shelf** dropdown to filter by warehouse location
4. Use the **Product Name** dropdown to drill into a specific product
5. All KPI cards and charts update automatically

## ⚙️ How It Works

### Data Flow

```
Transactions Sheet          Calculation Sheet          Dashboard Sheet
(Raw event log)    ──►     (PivotTable engine)  ──►   (Visual layer)
 ↓                          ↓                          ↓
 Date                       Monthly aggregations       KPI Cards
 Product Id                 Per-product totals         Trend Chart
 Receipt / Dispatch         Bottom-10 ranking          Bottom-10 Table
 Quantity                   Availability %             Slicers / Filters
```

### How to Add New Data

**Adding a new product:**
1. Open the **Products** sheet
2. Add a row: `P-021 | Product Name | Shelf X | Re-Order Level | Re-Order Qty`
3. Refresh PivotTables: **Data → Refresh All**

**Logging a new transaction:**
1. Open the **Transactions** sheet
2. Add a row: `Date | Product Id | Receipt or Dispatch | Quantity`
   - Receipts: positive quantity (e.g. `120`)
   - Dispatches: negative quantity (e.g. `-45`)
3. Refresh PivotTables: **Data → Refresh All**
